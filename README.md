# My Interactive Calculator

## Project Description

This project is a simple calculator webpage made using HTML, CSS, and JavaScript.

It can perform basic mathematical operations using buttons.

## Features

* Simple calculator design.
* Addition (+).
* Subtraction (-).
* Multiplication (*).
* Division (/).
* Clear button (AC).
* Interactive buttons.

## Technologies Used

* HTML: To create the webpage and buttons.
* CSS: To style the calculator.
* JavaScript: To handle button clicks and calculations.

## Project Files

* `index.html` – The structure of the calculator.
* `style.css` – The design and colors.
* `script.js` – The calculator functions.

## How to Run

1. Download or copy the project files.
2. Keep all three files in the same folder.
3. Open `index.html` in your web browser.
4. Start using the calculator.
